## 2. バトルシステム詳細

### 2.1 ターン進行フロー

```
【バトル開始】
  ↓
【ターン開始】
  ↓
【行動順序決定】← 全キャラ素早さ比較で順序決定
  ↓
【行動者の選択】
  ├─ 通常攻撃
  ├─ スキル使用
  ├─ 防御
  └─ アイテム使用
  ↓
【ダメージ計算】
  ↓
【ステータス異常チェック】
  ↓
【全員行動完了か？】
  ├─ NO → 次の行動者へ
  └─ YES → 敵全滅 or プレイヤー敗北をチェック
  ↓
【勝敗判定】
  ├─ 敵全滅 → 【クリア】
  ├─ プレイヤーHP0 → 【敗北】
  └─ 継続 → 【ターン終了】→ 【ターン開始】へ
```

### 2.2 行動順序決定アルゴリズム

**式：**
```
行動順序値 = (素早さ × 1.5) + ランダム値（-10～+10）
※ スキルの優先度によって調整される場合がある
```

**例**
- プレイヤー素早さ 8 → 行動順序値：12～32
- モンスターA素早さ 15 → 行動順序値：22.5～42.5
- モンスターB素早さ 10 → 行動順序値：15～35

**結果（ランダム値が平均的な場合）：**
1. モンスターB（素早さ 15）
2. プレイヤー（素早さ 8）
3. モンスターA（素早さ 10）

### 2.3 ダメージ計算式

#### 2.3.1 物理ダメージ

```
基礎ダメージ = (攻撃側ATK × 1.2 - 防御側DEF × 0.5) × スキル威力 / 100

属性相性による補正 = 
  ├─ 相手が有利属性の場合：× 0.75
  ├─ 相手が不利属性の場合：× 1.5
  └─ 通常：× 1.0

最終ダメージ = 基礎ダメージ × 属性相性 × クリティカル倍率

※ 最小ダメージは 1
```

**例：プレイヤーATK 20, モンスターDEF 8, スキル威力 120, 有利属性**
```
基礎ダメージ = (20 × 1.2 - 8 × 0.5) × 120 / 100
            = (24 - 4) × 120 / 100
            = 20 × 1.2
            = 24

最終ダメージ = 24 × 1.5（有利属性） = 36
```

#### 2.3.2 魔法ダメージ

```
基礎ダメージ = (攻撃側INT × 1.2 - 防御側RES × 0.5) × スキル威力 / 100

属性相性による補正 = 
  ├─ 相手が有利属性の場合：× 0.75
  ├─ 相手が不利属性の場合：× 1.5
  └─ 通常：× 1.0

最終ダメージ = 基礎ダメージ × 属性相性 × クリティカル倍率

※ 最小ダメージは 1
```

#### 2.3.3 クリティカル

```
クリティカル率 = スキル依存の基本クリティカル率 + (素早さ / 100)

クリティカル時の倍率 = 1.5倍
```

**例：スキルのクリティカル率 10%、素早さ 20**
```
最終クリティカル率 = 10% + (20 / 100) = 10% + 20% = 30%
```

### 2.4 回復スキル

```
回復量 = (自身INT × 1.5 + レベル) × スキル効果度 / 100

例：INT 15, レベル 10, スキル効果度 150
回復量 = (15 × 1.5 + 10) × 150 / 100
       = (22.5 + 10) × 1.5
       = 48.75 → 48 HP回復
```

### 2.5 状態異常システム

| 状態異常 | 効果 | 継続ターン | 発生確率 |
|--------|------|---------|--------|
| 毒 | 毎ターン最大HP 5%ダメージ | 3ターン | スキル依存 |
| 麻痺 | 素早さ -30% | 2ターン | スキル依存 |
| 睡眠 | 1ターン行動不可 | 1-2ターン | スキル依存 |
| 混乱 | 行動がランダム（敵味方共） | 2ターン | スキル依存 |
| 防御低下 | DEF -40% | 3ターン | スキル依存 |
| 攻撃低下 | ATK -40% | 3ターン | スキル依存 |
| 封印 | 特定スキル使用不可 | 1ターン | スキル依存 |

**例：毒の場合（最大HP 100）**
```
毎ターンダメージ = 100 × 5% = 5 ダメージ / ターン
```

## 3. レベルアップシステム

### 3.1 必要経験値表

| レベル | 必要EXP | 累計EXP |
|--------|--------|--------|
| 1→2 | 100 | 100 |
| 2→3 | 150 | 250 |
| 3→4 | 200 | 450 |
| 4→5 | 300 | 750 |
| n→n+1 | 100 × n × 1.2 | - |
| 50（最大） | - | - |

**計算式：**
```
必要EXP(n→n+1) = 100 × n × 1.2
```

### 3.2 レベルアップボーナス

レベルが1上がるごとに、以下のステータスが上昇：

```
HP += 5 + (レベル × 0.2)
ATK += 1 + (レベル × 0.1)
DEF += 0.8 + (レベル × 0.08)
SPD += 0.5 + (レベル × 0.05)
INT += 1 + (レベル × 0.1)
RES += 0.8 + (レベル × 0.08)
```

**例：Lv1→Lv2 の場合**
```
HP += 5 + (2 × 0.2) = 5.4 → 5
ATK += 1 + (2 × 0.1) = 1.2 → 1
```

### 3.3 転職システム

**転職時のステータス変化**

- HP：変化なし
- ATK / INT：+20%
- DEF / RES：+15%
- SPD：種族依存（±10%の範囲で変動）

**例：モンスター Lv20時に転職**
```
転職前：HP 150, ATK 30, DEF 20
転職後：HP 150, ATK 36, DEF 23
```

## 4. 合成システム

### 4.1 同種モンスター合成

**合成条件：**
- 同じモンスター × 2体
- 合成素材費：コイン 1,000～10,000（レアリティ依存）

**合成結果：**
- 1体のモンスターに統合
- ステータス +10% 上昇
- レベルは低い方に統一

**例：モンスターA Lv20 HP 200 + モンスターA Lv15 HP 150**
```
結果：モンスターA Lv15 HP 220（200 × 1.1）
```

### 4.2 異種モンスター合成（上位進化）

**条件：**
- 指定された特定の2体の組み合わせ
- 進化素材アイテム必要
- 合成素材費：コイン 5,000～50,000

**例：**
- モンスター「フレイム」+ モンスター「アイス」 → 「フレイムキング」

## 5. 凸（限界突破）システム

### 5.1 凸のルール

**凸条件：**
- 同じモンスター（レアリティ同じ）× 2体
- 凸素材費：コイン（凸数に応じて増加）

**凸ボーナス：**

| 凸数 | HP | ATK | DEF | SPD | INT | RES | コイン費用 |
|-----|-----|-----|-----|-----|-----|-----|---------|
| +0 | - | - | - | - | - | - | - |
| +1 | +5% | +3% | +3% | +2% | +3% | +3% | 500 |
| +2 | +5% | +3% | +3% | +2% | +3% | +3% | 1000 |
| +3 | +5% | +3% | +3% | +2% | +3% | +3% | 2000 |
| +5 | +5% | +3% | +3% | +2% | +3% | +3% | 5000 |

**累計ボーナス（+5まで）：**
```
HP: +25%
ATK / INT: +15%
DEF / RES: +15%
SPD: +10%
```

**例：SSRモンスター Lv50 HP 300 を +3まで凸**
```
基礎HP 300 × (1 + 0.15) = 345 HP
```

### 5.2 凸段階の上限拡放

**段階別上限：**
- 初期状態：+0（上限なし）
- ガチャで同一モンスター獲得時：+1ずつ上昇
- イベント報酬：+1～+3を獲得可能

## 10. 報酬システム

### 10.1 クエスト報酬

```
経験値 = (敵レベル × 10 + 敵の合計HP/10) × 難易度倍率

コイン = (敵レベル × 5 + 敵ATK) × 難易度倍率
```

**例：Lv10敵、HP 100、ハード難易度**
```
経験値 = (10 × 10 + 100/10) × 1.5 = (100 + 10) × 1.5 = 165 EXP
コイン = (10 × 5 + 15) × 1.5 = 65 × 1.5 = 97 コイン
```

### 10.2 ボスレイド報酬

**参加報酬：**
- 基本報酬 = 敵Lv × 100 + 難易度倍率
- 参加人数補正：4人 = ×1.0, 3人 = ×0.8, 2人 = ×0.6, 1人 = ×0.3

**撃破報酬（ボスHP 0になった時）：**
- 基本報酬 × 3 + 限定アイテムドロップ

## 11. PvP（ランクバトル）バランス

### 11.1 パワースコア計算

```
パワースコア = (HP + ATK×2 + DEF + SPD + INT×2 + RES + 装備補正) × レアリティ補正

※ プレイヤーとモンスター2体のパワースコア合計
```

### 11.2 マッチング基準

```
マッチング幅 = プレイヤーパワースコア ± 20%
```

**例：パワースコア 1000の場合、800～1200のプレイヤーとマッチング**
